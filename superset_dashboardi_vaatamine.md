# Dashboardi vaatamine Apache Supersetis

1. Ava veebibrauseris Superseti aadress:

   ```text
   http://localhost:8088
   ```

2. Sisesta Superseti kasutajanimi ja parool ning logi sisse.

3. Vali ülemisest menüüst **Dashboards**.

4. Avanenud nimekirjas klõpsa olemasoleva dashboard'i nimel.

5. Dashboard avaneb ning sellel olevaid jooniseid ja andmeid saab vaadata.
